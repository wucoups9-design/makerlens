# 新场景测试与人工复核

## 首轮采集

先拍 6–10 段、每段 10–20 秒的新视频作为初步检查，包含手套/裸手、白长袖、印花衣服、护目镜/普通眼镜、侧面、远距离、部分遮挡及无目标背景。记录参与者代号、拍摄场次、背景和时间；尽量使用未参与训练的人物与场次。数量只是起点，不代表统计充分。

记录仅保存在私有资料目录。人物拍摄应获同意；不必启动机器即可采集检测所需画面。

## 固定测试资料

1. 为每段原视频登记文件 SHA-256、匿名参与者代号、场次代号、采集日期、条件和用途。
2. 在查看预测前确定抽帧间隔和标签规范，保留空目标帧，避免只挑容易识别的画面。
3. 人工标注并复核所有测试框；对过渡帧、遮挡和普通眼镜的处理作记录。
4. 固定模型文件 SHA-256、图像大小、阈值和评估方式，再执行第一次评估。
5. 同时保存正式指标和固定阈值下的 TP/FP/FN；按人物、场次和困难条件报告结果。

新视频尚未提供时，测试状态必须记为“待采集”，不可用旧视频替代并标为完成。

## 错误记录模板

在本机检测页面完成检测后，填写“记录本次人工复核”，选择错误类型、真实类别并填写位置/场景意见，点击保存。下载的 JSON 包含输入图片 SHA-256、两个模型的 SHA-256、显示阈值和所有预测框，原图不嵌入记录。每个问题保存一份，保存在私有资料目录；这些是人工观察记录，尚不等于经过标注匹配计算的测试指标。

每项记录包括：样本代号、模型版本、帧时间、真实类别、预测类别、错误类型（漏检/误检/框不准/标签疑问）、场景条件、人工复核意见、处理状态。

复核时同时查看真值和预测。框不准需要记录匹配标准；无检测不意味着无目标。场景问题不能仅凭一项平均指标下结论。

## 补数据和训练门槛

错误分析后另行采集训练素材。同一参与者/场次尽量不跨训练和最终测试集合。如果将已观察的测试素材用于训练，应重新建立最终测试集，并记录旧测试已转为开发资料。

每次训练前必须：

- 给用户展示此次全部训练图片和对应框，包含原有图片及新增图片。
- 提供完整 CVAT 图片与标注包以及数量清单。
- 固定最终版本的文件哈希，记录用户对该版本完成复核。
- 获得用户明确的开始训练指令；图片或标签更改后重新确认。

推理和错误登记不自动启动训练。训练完成后保存配置、数据版本、模型哈希与评估结果。
