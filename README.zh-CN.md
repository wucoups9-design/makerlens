# MakerLens：STEM 工作坊视觉辅助原型

项目把护目镜、眼部、手套和裸手识别用于教师人工复核。当前提供本机图片检测页面，以及图片/视频推理程序。

## 打开真实检测页面

老师可勾选“手套与裸手”“护目镜与眼部”：只选前者仅运行手套模型，只选后者仅运行护目镜模型，两项都选则同时检测。至少选择一项；切换选择后需重新检测。复核记录保存此次实际检测项目。

命令行图片或视频检测也支持 `python ml/run.py 输入文件 --mode gloves`、`--mode goggles` 或 `--mode both`（默认）。

准备 Python 环境及私有权重后，在仓库目录运行：

```sh
python ml/serve.py --goggles /path/to/goggles-v1.pt --gloves /path/to/gloves-v3-cleanstart.pt
```

浏览器打开 `http://127.0.0.1:8765`，选择图片，点击“开始检测”。页面显示检测框、类别、置信度，并支持保存结果图。服务只监听本机；图片处理结束后临时文件自动清除。关闭服务所在终端会结束服务。

仓库根目录 `index.html` 是早期仪表盘展示。真实检测入口是上述本机网页服务；静态托管本身不能运行 Python 模型。

本机页面也提供仪表盘入口，两者可以互相切换。检测后可填写漏检、误检、框不准等人工记录并下载 JSON，用于后续补拍与复核；记录不会触发训练。

## 已完成的工作

- 使用两个 YOLO11n 微调模型执行同画面的检测。
- 对 149 张手套训练图进行用户复核后，训练 clean-start 候选模型。
- 记录评估指标、误检与漏检，并保留本地演示流程。
- 当前代码和使用说明集中在 `ml/`；根目录的旧版 Python 文件和报告保留作历史记录。

模型仍会把白衣袖或衣物图案误认成手，在遮挡或陌生场景中漏检眼部。现有 17 张手套测试图已用于开发比较，不能当成新的最终测试。新场景采集及复核流程见 [复核与迭代](docs/REVIEW_WORKFLOW.md)。

贡献主要是数据整理、标注复核、迁移学习、实验评估与应用集成。图像框用于提示人工检查，不能直接推断课堂安全或控制设备。
