# MakerLens：STEM 工作坊视觉辅助原型

项目把护目镜、眼部、手套和裸手识别用于教师人工复核。当前提供本机图片检测页面，以及图片/视频推理程序。

## 打开真实检测页面

老师可勾选“手套与裸手”“护目镜与眼部”：只选前者仅运行手套模型，只选后者仅运行护目镜模型，两项都选则同时检测。至少选择一项；切换选择后需重新检测。复核记录保存此次实际检测项目。

命令行图片或视频检测也支持 `python ml/run.py 输入文件 --mode gloves`、`--mode goggles` 或 `--mode both`（默认）。

准备 Python 环境及私有权重后，在仓库目录运行：

```sh
python ml/serve.py --goggles /path/to/goggles-v1.pt --gloves /path/to/gloves-v3-cleanstart.pt
```

浏览器打开 `http://127.0.0.1:8765`，选择图片，点击“开始检测”。页面显示检测框、类别、置信度，并支持保存结果图。服务只监听本机；图片处理结束后临时文件自动清除。关闭服务所在终端会结束服务。

仓库根目录 `index.html` 是早期仪表盘展示。真实检测入口是上述本机网页服务；静态托管本身不能运行 Python 模型。

本机页面也提供仪表盘入口，两者可以互相切换。检测后可填写漏检、误检、框不准等人工记录并下载 JSON，用于后续补拍与复核；记录不会触发训练。

## 金属陀螺草图 AI 反馈原型

根目录 `index.html` 现提供陀螺设计草图迭代页面。学生明确勾选同意并点击分析后，浏览器才会把压缩草图与设计说明发送给本机 Python 后端；后端使用阿里云百炼 Qwen 的 OpenAI 兼容接口生成初步问题。页面不会把 API 密钥放入浏览器，也不会在服务端保存草图。AI 输出只是需要学生核实的建议，不判断精确尺寸、加工可行性或安全；学生需留下采纳/不采纳决定和依据。

本地启动（需 Python 3）：

后端也支持读取本机用户目录 `.config/makerlens/bailian.json` 中的 `DASHSCOPE_API_KEY`、`BAILIAN_BASE_URL` 和 `BAILIAN_MODEL`。该配置位于仓库之外，不通过网页提供；环境变量优先。已有本机配置时，直接运行 `python3 sketch_feedback_server.py --port 4173` 即可。

```sh
export DASHSCOPE_API_KEY='在本机终端粘贴你自己的百炼 API Key'
python3 sketch_feedback_server.py --port 4173
```

然后访问 `http://127.0.0.1:4173/`。不要把 API Key 写入网页文件、Git 或聊天内容。未设置密钥时，网页仍可保存草图版本，但 AI 分析会被后端拒绝；点分析按钮不会产生模型调用费用。配置密钥并真正点击分析后，图像与说明会发往百炼，可能产生 API 费用，课堂使用前须先取得适当授权并避免输入学生姓名、学校等个人信息。

当前后端默认仅监听 `127.0.0.1`，仅适合本机演示。学生异地线上测试需要另行部署受保护的 HTTPS 后端、配置服务器密钥、限流/访问控制，并确认学校的数据与家长/学生授权要求；不能直接公开这个本机原型。

# 功能完整版本（2026-10-03）

在项目目录执行 `python3 dev_server.py --port 8766 --sketch-ai`，或双击 `run_features.command`，打开 `http://127.0.0.1:8766/`。默认沿用原测试端口，便于在同一浏览器读取旧学习档案。新版把旧的 `active` 记录迁移到多作品工作区，原记录键保留；不同端口/浏览器的本地档案需先导出再导入。

- 学生：多作品管理、草图版本与对比、按需 AI 建议、固定设计检查清单、采纳理由、工序学习、过程记录、变量测试与平均值、成品建议、反思和成果海报。
- 教师：独立身份验证、发布任务/材料/截止日期/交互场景、全班进度筛选、逐条证据复核、整体评价、现场观察及处理日志。
- 档案：本地 IndexedDB、手动课堂同步、换设备凭证、冲突保护、JSON/CSV 导出与新增导入。换设备凭证不包含在学习档案中，单独私下保存。课堂服务器是一所试点课堂，尚未实现多学校租户隔离或学校统一身份认证。
- 摄像头：仅预览、提示音测试、自动学习留档，以及已有识别接口。PPE 模型暂停期间不输出佩戴结论。连续识别准确率和学校真实设备仍需后续验证。

本机教师预览通过“教师工作区 → 进入本机教师预览”打开，只在 loopback 开发服务提供；正式服务使用独立教师管理码，没有此免码入口。`--sketch-ai` 仅使用已有服务端百炼配置，密钥不会发给浏览器。未配置时仍可使用其余功能与固定检查清单。

正式服务可添加 `--features-only` 暂停 PPE 模型加载，草图/制作/成品建议与课堂功能继续可用。新增 `MAKERLENS_CLASSROOM_DB` 配置课堂 SQLite 路径，默认 `/var/lib/makerlens/classroom.sqlite3`。生产数据库应定期在服务端备份；仓库已忽略数据库文件。更新反向代理时使用新版白名单，允许新前端文件及 `/api/classroom/…` 路由。本次本地实现没有改动已部署的腾讯云网站。

功能回归：安装 Playwright 并有 Chrome 后，执行 `node tests/features.cjs`；可用 `MAKERLENS_PYTHON` 指定 Python。此测试使用临时数据库、隔离浏览器和合成图片，不调用真实模型或摄像头。可选真实建议接口检查 `node tests/live-advice.cjs` 会调用百炼，应仅在希望进行真实 AI 测试时运行。
